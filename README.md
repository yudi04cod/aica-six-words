# Aica Six Words

One complete story in exactly six words — a whole life implied in a
single line, and a quiet turn at the end of it.

> The last candle outlived its keeper.

## How it works

- `main.py` (standard library only, deterministic) writes the story to
  `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

Run `python3 main.py` to produce the output file.
